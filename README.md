# EduPulse - Next-Gen Student Management System

EduPulse is a comprehensive, responsive, single-page web application for academic management, tracking students, courses, attendance, grades/GPA, and tuition fees.

## 🚀 Key Features

- **Executive Dashboard:** Live KPI metric cards, SVG grade distribution bar charts, and academic risk alerts.
- **Student Directory (CRUD):** Live search (`Press / to focus`), multi-criteria filtering (Department, Year Level, Status), and CSV export.
- **Tabbed Student Profiles & Official Transcripts:** Complete student records, weighted 4.0 GPA calculator, attendance percentage, fee balance, and printable academic transcripts.
- **Course & Roster Management:** Course catalog with interactive student course enrollment roster manager.
- **Daily Attendance Logger:** Batch attendance logger by date & course with instant student percentage calculations.
- **Tuition & Fee Manager:** Fee status tracking, payment logger, and digital payment receipts.
- **Theme & Persistence System:** Glassmorphic UI with Dark & Light theme toggling, LocalStorage auto-save, JSON backup export, and 1-click demo data reset.

## 🛠 Tech Stack

- **HTML5 & Vanilla JavaScript (ES6 Modules)**
- **CSS3 Design System:** Custom properties, glassmorphism backdrop filters, CSS animations.
- **FontAwesome & Google Fonts (Outfit, Plus Jakarta Sans)**

## 💻 Usage & Deployment

Since EduPulse is built using standard HTML5, CSS3, and ES6 JavaScript modules, it requires no build steps or backend servers:

- **Open Directly:** Open `index.html` directly in any modern web browser.
- **GitHub Pages:** Enable GitHub Pages in your repository settings (`Settings -> Pages -> Branch: main`) for instant free web hosting.
